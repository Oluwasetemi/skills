# Skills Repo Instructions

- Each skill lives in `skills/<skill-name>/` and must contain `SKILL.md`.
- Skill names and folder names should be kebab-case and match the `name` frontmatter.
- Keep skill folders minimal: `SKILL.md`, optional `scripts/`, optional `references/`, optional `assets/`.
- Do not add README/changelog/install docs inside individual skill folders; put repo-level docs in the root README.
- When editing a skill, preserve trigger guidance in the frontmatter `description` and keep the body focused on execution steps.
